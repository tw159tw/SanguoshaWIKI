# 三国杀一将成名 WIKI · 桌面图鉴

一款面向《三国杀》玩家的非营利桌面图鉴，用于查阅武将、技能、皮肤及台词，并在本机管理个人收藏、等级排序和22配阵。

本仓库用于发布安装程序、更新包、版本说明与使用介绍，暂不公开详细源代码。

## 下载与更新

请从本仓库的 **Releases** 页面下载最新版。

- **首次安装**：下载 `SanguoshaWIKI-Setup-1.0.3-x64.exe`。
- **更新现有安装**：下载 `SanguoshaWIKI-v1.0.3-Universal-Update.zip`，解压后按包内说明操作。更新前请关闭程序，并建议先导出个人备份。
- 当前提供 **Windows x64** 安装包与更新包，尚未提供 macOS、Linux、Android 或 iOS 安装版本。
- 同版本修订请以最新 Release 附件为准；程序版本仍为 v1.0.3。

## 主要功能

- 武将图鉴：搜索、组合筛选、武将包统计、收藏进度与已拥有/喜爱/想获得标记。
- 武将档案：按版本查阅技能，嵌套引用技能支持悬停显示详情。
- 皮肤与头像：完整原图预览、初始/至臻形态切换、头像裁切与对应台词试听。
- 技能池：入口位于对应技能旁，保留分类、随机抽取、技能悬停详情与武将跳转；蒲元五张武器牌位于“铸刃”旁。
- 自定义等级排序：多分页、拖动排序与撤销。
- 22配阵：编排武将组合、备注与拖动调整。
- 本地个人资料备份、媒体缓存、分组选择离线下载与重试。
- 深色及浅色主题。

当前图鉴总数为737名（正式武将667名、体验卡30名、限时武将40名，不含仅自走棋武将）；收藏进度仅统计正式武将。

## v1.0.3 本轮修订

- 优化浅色模式文字、特殊技能标签和自走棋词条的可读性；技能类型仅在描述开头标色。
- 调整鲍三娘体验卡的品质、帅点与默认形象。
- 调整缺少完整立绘的提示位置，增加排序分页关闭功能。
- 离线下载列表按武将包分组，支持全选、整组勾选与补充下载新增内容。
- 全量核对现行及历史技能引用，增加下划线与详情提示。
- 精简资料与媒体检查列表的显示。
- 新增10位武将的技能池和蒲元武器牌，池内按来源武将的大包/小包顺序显示。
- 档案标签、评级和心得自动保存，关闭或跳转前补存，失败时保留输入并提示重试。
- 补齐17款皮肤的初始/至臻两套图像与台词，默认显示所选形态的动态，两种形态均可选作头像，并纳入离线下载。
- 逐一核对限定专属与群英荟萃的皮肤原页；全武将包优先显示Wiki横版大图，头像裁切独立保存。
- 江海同舟、冥等纯体验卡武将包不再显示全收集。
